# COOPROMU Web

Sitio web oficial de **COOPROMU** (Cooperativa de Productores Municipales) — una cooperativa sin ánimo de lucro comprometida con el desarrollo sostenible, la comercialización local y el bienestar de la comunidad en La Playa de Belén, Norte de Santander, Colombia.

## Tecnologías

- **React 18** + **TypeScript 5**
- **Vite 5**
- **Tailwind CSS 3**
- **Framer Motion 12**
- **Lucide React** (iconos)

## Desarrollo

```bash
npm install
npm run dev      # servidor local
npm run build    # build producción
npm run preview  # previsualizar build
```

## Scripts disponibles

| Comando | Descripción |
|---------|-------------|
| `npm run dev` | Inicia servidor de desarrollo |
| `npm run build` | Compila para producción |
| `npm run preview` | Previsualiza el build |
| `npx tsc --noEmit` | Verifica tipos TypeScript |
| `npx eslint src` | Verifica código con ESLint |
